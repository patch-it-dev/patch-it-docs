patch-it is Dependabot for APIs. When an API your app relies on changes, patch-it finds the exact lines it will break and opens a pull request with the fix. Other tools send an alert. We send the fix.

- **Runs in your CI**, on your own model key, so your code never leaves your environment.
- **Opens a PR when it's confident**, and an issue when it isn't.
- **Covers Stripe, OpenAI and Anthropic today.** Packages and runtimes are next.
